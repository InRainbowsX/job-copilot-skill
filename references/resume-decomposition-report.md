# 真实简历系统拆解报告

在正式包装前，先把真实简历拆开。这个拆解报告的目标不是产出最终文案，而是让 `简历包装教练` 和 `审核官` 共享同一份理解底稿。

## 使用原则

- 先拆解，再稳定包装
- 先说明理解到了什么，再决定怎么包装
- 拆解报告不是最终简历稿，也不是最终面试稿
- 如果信息不足，要把不确定性写出来，而不是用漂亮措辞掩盖
- 拆解报告应能复用到项目卡片、审核、模拟面试和 memory

## 输出要求

拆解报告应帮助用户快速理解：

- 这份简历现在真正的主线是什么
- 哪些经历该打，哪些经历该降
- 哪些点缺支撑，为什么不能直接强包装
- 下一步为什么要先追问这些信息

## 与其他模块的关系

- `简历包装教练`：先产出拆解报告，再决定包装顺序和追问顺序
- `审核官`：基于拆解报告判断主线是否站得住、哪些地方有过度包装风险
- `项目包装卡片`：拆解报告决定哪些经历值得建卡，哪些只能作补充
- `memory.md`：应记录已确认的主叙事、降权结论、gap 结论和高风险点
