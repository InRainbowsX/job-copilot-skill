# 回归测试集

回归测试集用于沉淀已经修过、或已经被确认存在过的关键行为问题。目标是防止后续改动把旧问题重新带回来。

## 纳入标准

满足以下任一条件的行为问题，应考虑加入回归集：

- 已在真实使用中出现过
- 已被用户明确指出
- 已有对应 issue / PR 修复
- 一旦回归会显著影响核心体验

## 回归案例格式

每条案例至少包含：

- `问题名称`
- `来源 issue / PR`
- `输入 prompt`
- `修复前常见错误`
- `修复后预期行为`

## 首批回归案例

### 回归 1：状态块缺失

来源 issue / PR：

- `#13`
- `#26`

输入 prompt：

`使用 $job-copilot-skill 直接帮我修改简历。`

修复前常见错误：

- 一上来直接进入改写
- 没有 `当前阶段 / 当前任务 / 下一步推荐`

修复后预期行为：

- 首轮必须先显示状态块
- 必须先说明当前正在做诊断或深挖

### 回归 2：直接跳过诊断进入改写

来源 issue / PR：

- `#14`

输入 prompt：

`使用 $job-copilot-skill 帮我把这份简历改得更高级。`

修复前常见错误：

- 不做问题诊断
- 不追问缺失信息
- 直接输出完整定稿

修复后预期行为：

- 先指出问题和推荐方向
- 信息不足时先追问

### 回归 3：远期校园经历误判为主叙事

来源 issue / PR：

- `#23`

输入 prompt：

`使用 $job-copilot-skill 分析我的社招简历。我有很强的校园项目，但最近两年有新的工作经历。`

修复前常见错误：

- 只因为校园项目更亮就直接定为主叙事

修复后预期行为：

- 明确社招时间轴
- 优先评估最近经历
- 解释校园经历是补充亮点还是主项目

### 回归 4：gap 被忽略或被伪装成正式经历

来源 issue / PR：

- `#24`
- `#25`

输入 prompt：

`使用 $job-copilot-skill 帮我解释 gap。我这段时间主要在写小说和做个人内容项目。`

修复前常见错误：

- 直接忽略 gap
- 直接写成固定公司任职

修复后预期行为：

- 识别为 gap 或非标准经历
- 要求进一步确认投入和产出
- 保持包装边界

### 回归 5：支持型岗位的数据信号被误删

来源 issue / PR：

- `#88`
- `#93`

输入 prompt：

`使用 $job-copilot-skill 改写我的 HR Ops 简历。我有很多报表、FAQ、系统维护和政策提醒工作，这些其实是我最贴岗位的内容。`

修复前常见错误：

- 默认把这些内容当成低价值事务
- 为了更“好看”直接删掉这些信号

修复后预期行为：

- 识别这些内容在支持型岗位里的价值
- 将其保留并改写为支撑能力、流程能力或合规能力

### 回归 6：篇幅约束机械执行导致候选人变弱

来源 issue / PR：

- `#89`
- `#93`

输入 prompt：

`使用 $job-copilot-skill 把我的简历压成 4 / 3 / 3，但不要把最能证明我适合 SSC 的 FAQ、报表和政策预警内容删掉。`

修复前常见错误：

- 先机械压缩条数
- 为了形式整齐删掉更强的 role-fit 证据

修复后预期行为：

- 先判断价值线再决定条数
- 不允许条数约束压过岗位价值判断

### 回归 7：弱简历被当成普通润色处理

来源 issue / PR：

- `#73`

输入 prompt：

`使用 $job-copilot-skill 评估我的简历。我有明显 gap，最近经历也不强。`

修复前常见错误：

- 不给市场判断
- 不给强包装判断
- 直接按普通润色进入改写

修复后预期行为：

- 首轮给出市场评分或等效判断
- 明确是否需要强包装
- 先停留在诊断与路线判断阶段

### 回归 8：未锁方向就直接给最终包装稿

来源 issue / PR：

- `#74`

输入 prompt：

`使用 $job-copilot-skill 包装我的简历。我可能投内容运营、商家运营或广告优化。`

修复前常见错误：

- 不做路线比较
- 不说明主方向是否已锁定
- 直接输出最终版简历

修复后预期行为：

- 先比较可能路线
- 给出主方向、次方向和证据
- 未锁定前不输出最终定稿

### 回归 9：简历会话跑偏成项目教程

来源 issue / PR：

- `#76`

输入 prompt：

`使用 $job-copilot-skill 处理我的 gap，我在想要不要做一个小红书账号。`

修复前常见错误：

- 直接展开小红书运营教程
- 没有回到简历中的定位、作用和风险

修复后预期行为：

- 先回到简历和面试主线
- 先判断这类项目在简历中的位置、价值和边界
- 如要扩展建议，也先围绕包装和可解释性

### 回归 10：当前阶段未完成就提前执行下一阶段

来源 issue / PR：

- `#77`

输入 prompt：

`使用 $job-copilot-skill 先完成简历，再直接开始模拟面试。`

修复前常见错误：

- 当前简历仍未达标却直接进入模拟面试
- 没有明确 release / blocked 判断

修复后预期行为：

- 先给出当前阶段是否放行
- 未放行时明确卡住原因
- 只把下一阶段作为推荐，不提前执行

## 维护规则

- 每次修复真实行为问题时，评估是否需要补进回归集
- 如果某条回归案例已经失效，应说明原因后再调整或移除
- 回归集不追求覆盖全部场景，只覆盖高风险、已发生、值得长期守住的问题
