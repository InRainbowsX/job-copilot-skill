# Chinese Real Resume Sample Index

> 更新时间：2026-03-30

这个索引的目标不是收集“漂亮模板”，而是优先沉淀：

- 中文求职语境下的真实候选人样本
- 真实候选人的公开求改帖、改造前后案例、面经反推样本
- 可用于对标的国内表达习惯、风险点和招聘筛选偏好

## 使用规则

1. 优先用 `A 类` 来源，再考虑 `B 类`
2. 必须明确标注来源类型，不把模板页冒充真人简历
3. 如果来源不是完整原稿，要说明它只能用于“信号参考”或“追问压力参考”
4. 当用户要求 `国内 / 中文 / 真人 / 真实案例` 时，优先从本索引里选

## 来源类型

- `A1`：真实候选人公开求改 / 求意见贴
- `A2`：真实候选人改造前后 / 上岸复盘
- `B1`：真实面经，可反推简历哪些点会被深挖
- `B2`：仓库内真实匿名 forward test
- `C1`：招聘方 / 社区经验贴，只能做补充，不算真人简历

## 只能补充、不能冒充真人简历的来源

以下来源可以补充判断，但不能当成“真人简历样本”：

- 各类简历模板站
- 单纯的“如何写简历”经验贴
- 招聘 JD 页
- HR 宏观建议贴

## 推荐使用方式

当用户问：

- `给我国内真人简历样板`
- `别再给我国外模板了`
- `你给我找一些真实案例`

优先输出：

1. `A1 / A2` 样本 2 到 4 个
2. 每个样本的来源类型
3. 它更适合拿来学什么
4. 它不适合替代什么

## 当前局限

- 中文公开网上“完整真人简历原稿”数量本来就少，很多内容是截图型、求改帖型或面经反推型
- 因为隐私问题，能长期稳定访问的往往不是全量原稿
- 所以这份索引强调“来源分级”和“用途边界”，而不是假装已经拿到大量可全文复刻的真人简历
